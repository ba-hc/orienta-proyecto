# Identidad gráfica aplicada a Orienta E2

Recursos descargados del [sitio oficial de Normas Gráficas UdeC](https://normasgraficas.udec.cl/) el27/10/2026. Se conserva el SVG del logosímbolo horizontal y un PNG de alta resolución para compatibilidad de PowerPoint. La aplicación en las diapositivas recorta solo el lienzo blanco exterior, conserva la marca completa y su proporción, y mantiene resguardo en el diseño. El uso identifica un trabajo académico del Grupo9; no representa una aprobación institucional del producto.

Poppins y Roboto son las tipografías publicadas por la UdeC. Se incluyen archivos estáticos para editar la presentación y sus licencias OFL originales. Para conservar el aspecto en otro equipo, instalar las seis fuentes de esta carpeta antes de abrir el PPT; el PDF conserva la composición exportada y fuentes incrustadas.

La paleta de la presentación usa azul#223C6A y amarillo#E69B0A. El prototipo de interfaz mantiene su propia identidad visual Orienta. La [procedencia y hashes](Procedencia_Identidad.json) permiten verificar los recursos. No se impone una licencia abierta a la marca universitaria.
